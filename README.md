# Quiver Launcher Settings

Collection of apps for [Quiver Launcher](https://github.com/tgeorgiadis/quiver-launcher).

## Contributing

Feel free to contribute by submitting a pull request with your changes. 

Apps are added following the `apps.json` format as described by [Quiver Lanucher README](https://github.com/tgeorgiadis/quiver-launcher/blob/main/README.md#your-own-app-list).
